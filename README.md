# Campus Calimate Action - Climate Action (SDG 13)

## Sustainable Development Goal
This app aim for create a lightweight mobile prototype tool adapted to college scenarios, so that students can easily record and calculate the carbon footprint of daily campus life. Motivate students to practice low-carbon behavior and learn more about climate change and set their own goal to achieve low-carbon activity.

## Project Description
The software solution, which is proposed in this project, is called Campus Climate Action, a campus-initiated application that is intended to assist students in monitoring their carbon footprint and taking part in low-carbon activities. The system enables the students to document the daily activities (commuting, eating, and campus drinking) and subsequently compute the carbon emissions and provide visual reports about their own carbon footprint. It also offers low-carbon challenges, reward systems, and environmental education content to encourage students to engage in permanent contributions to climate-friendly activities.

## Overview of SLDC
In our SDLC work, the planning phase is the first and most important step because it defines the overall direction of the project. During planning, we identify the problem, determine the project objectives, and gather user requirements.
The design phase comes after planning. In this stage, we transform the requirements into a structured system blueprint. This includes designing the system architecture, database structure, user interface, and process flow diagrams. We also decide on the technologies and tools to be used. Finally, the testing and evaluation phase ensures the system works as expected.

### Planning Phase
In the planning phase, our team identified the main problem, which is the lack of awareness among students about their daily carbon footprint. The objective of the project is to create a simple digital tool that can help students understand how their activities affect the environment. During this phase, we also gathered basic user requirements. For example, students should be able to record daily activities, view their estimated carbon footprint, gain knowledge on sustainibility and climate change, and receive suggestions for reducing emissions. The team used Trello to organize tasks and manage our sprint board. <br>

#### User Stories:
##### STUDENT 
1. As a student, I would want to Login using my student ID and create my own password account so I can do all the activity inside the application, and protect my information. 
2. As a Student I want to check my dashboard and see my progress on low-carbon activity so that I can keep track on all my activity  
3. As a student I want to read announcements post by campus admin and club members so that I don't miss any important event and activity  
4. As a student I want to see redeem catalogue so I know how many points I need to collect before I can redeem to get the reward I want 
5. As a student, I want to track and update the daily carbon dioxide I produce every day so that I know how many carbon emissions I generate and what activity I need to reduce to keep the carbon emission under control. 
6. As a student I want to join challenges so that I can get points and to learn more about the activity to prevent climate change. 

##### SUSTAINABILITY CLUB MEMBERS 
1. As a club member, I want to login using my Taylor’s account using my student ID and create my own password, so that I can protect my information and so that I can do all required activity as a club member. 
2. As a club member, I want to post announcements to students or my fellow members so that nobody misses important events and activities. 
3. As a club member I want to post challenge for student to participate and improve low-carbon activity in our university so that students can ear points and learn more about climate change and the importance of maintaining low-carbon lifestyle 
4. As a club member I want to see student submission of evidence and attendance in challenge, then approve the submission so that i can make sure the student that join challenge is attend and perform well so that the points are given to the rightful person
